## ข้อมูลนำเข้า

ไฟล์หลักเป็น `.xlsx` ที่มี 5 ชีท:

1. `all_courses` — รายวิชาที่เปิดสอนทั้งหมด รวมวิชาบริการ วิชานอกสาขา
   ผู้สอน ห้อง และเวลาที่ล็อกไว้ ระบบใช้ข้อมูลนี้ป้องกันตารางอาจารย์ชนกัน
2. `department_courses` — รายวิชาที่สาขาเป็นผู้จัดและต้องนำมาสร้างตาราง
   ระบุผู้สอน ประเภทห้อง จำนวนนักศึกษา `student_groups` และ `session_hours`
3. `student_courses` — รายวิชาที่ทุกกลุ่ม/ทุกชั้นปีต้องเรียน รวมวิชานอกสาขา
   และเวลาที่ล็อกไว้ ระบบใช้ข้อมูลนี้ป้องกันตารางเรียนชนกัน
4. `rooms` — ห้องเรียน ความจุ ประเภทห้อง สิทธิ์สำหรับระดับบัณฑิตศึกษา
   และช่วงเวลาที่ไม่พร้อมใช้งาน
5. `student_groups` — กลุ่มนักศึกษาตามสาขา/ชั้นปี จำนวนนักศึกษา
   และชั่วโมงเรียนสูงสุดต่อวัน

แอปยังอ่านไฟล์เดิมที่มีชีท `teach`, `study`, `student`, `room` ได้ เพื่อช่วยย้ายระบบ
และรับไฟล์ Preference เวลาสอนของอาจารย์แยกต่างหากแบบไม่บังคับ

รูปแบบเวลาใช้ตัวอย่าง `MW 09.00-10.30; F 13.00-16.00` และคั่นหลายรายการด้วย `;`

### `session_hours`

`session_hours` กำหนดว่าแต่ละวิชาเรียนกี่ครั้งต่อสัปดาห์ และแต่ละครั้งกี่ชั่วโมง
โดยความยาวของทุกครั้งต้องเท่ากัน จำนวนค่าคือจำนวนครั้งต่อสัปดาห์:

- `1.5,1.5` = 2 ครั้งต่อสัปดาห์ ครั้งละ 1.5 ชั่วโมง
- `2,2` = 2 ครั้งต่อสัปดาห์ ครั้งละ 2 ชั่วโมง
- `3` = 1 ครั้งต่อสัปดาห์ ครั้งละ 3 ชั่วโมง

### กลุ่มนักศึกษาที่เรียนแต่ละวิชา

ผู้ใช้ต้องกำหนดทุกกลุ่มและทุกชั้นปีที่จะเรียนแต่ละวิชาให้ครบใน
`department_courses.student_groups` โดยคั่นหลายกลุ่มด้วย `/`
ข้อมูลนี้ต้องเป็นผลที่สรุปแล้วจากการวิเคราะห์การสับหลีก เช่น
`Stat ปี 3/SIDS ปี 3` ระบบจะใช้ข้อมูลดังกล่าวป้องกันตารางของกลุ่มเหล่านี้ชนกัน

## พารามิเตอร์ที่ปรับได้

- ชั่วโมงสอนสูงสุดต่ออาจารย์ต่อวัน
- ชั่วโมงเรียนสูงสุดต่อกลุ่มต่อวัน
- ชั่วโมงสูงสุดของวิชาเดียวกันต่อวัน
- จำนวนวิชาสูงสุดต่ออาจารย์ต่อวัน
- ห้ามใช้ช่วง Preference เท่ากับ 0
- หลีกเลี่ยงการเรียนวิชาเดิมในวันติดกัน
- อนุญาตให้บางคาบยังไม่ถูกจัด เพื่อให้เห็นจุดติดขัด
- น้ำหนัก Preference ความพอดีของห้อง และโทษคาบเย็น
