# SCHEDU

เว็บแอปจัดตารางเรียน–ตารางสอนสำหรับสาขาวิชา ใช้ Streamlit และ Google OR-Tools 

## ข้อมูลนำเข้า

ไฟล์หลักเป็น `.xlsx` ที่มี 5 ชีท:

1. `all_courses` — รายวิชาที่เปิดสอนทั้งหมด รวมวิชาบริการและเวลาที่ล็อกไว้
2. `department_courses` — รายวิชาที่สาขาเป็นผู้จัดและต้องนำมาจัดตาราง
3. `student_courses` — วิชาที่แต่ละกลุ่มนักศึกษาต้องเรียน
4. `rooms` — ห้อง ความจุ ประเภท และช่วงที่ใช้ไม่ได้
5. `student_groups` — กลุ่มนักศึกษาตามสาขา/ชั้นปีและจำนวนนักศึกษา

แอปยังอ่านไฟล์เดิมที่มีชีท `teach`, `study`, `student`, `room` ได้ เพื่อช่วยย้ายระบบ
และรับไฟล์ Preference ของอาจารย์กับไฟล์รายชื่อแจ้งสับหลีกแยกต่างหากแบบไม่บังคับ

รูปแบบเวลาใช้ตัวอย่าง `MW 09.00-10.30; F 13.00-16.00` และคั่นหลายรายการด้วย `;`
รูปแบบคาบใน `session_hours` ใช้ `1.5/1.5`, `3` หรือเลขชั่วโมงแบบเดียวกัน

## เริ่มใช้งานบนเครื่อง

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

เปิด URL ที่ Streamlit แสดงใน Terminal แล้วใช้ข้อมูลตัวอย่างที่ฝังในแอป
หรืออัปโหลดไฟล์ของสาขาอื่นในโครงสร้างเดียวกัน

## พารามิเตอร์ที่ปรับได้

- ชั่วโมงสอนสูงสุดต่ออาจารย์ต่อวัน
- ชั่วโมงเรียนสูงสุดต่อกลุ่มต่อวัน
- ชั่วโมงสูงสุดของวิชาเดียวกันต่อวัน
- จำนวนวิชาสูงสุดต่ออาจารย์ต่อวัน
- ห้ามใช้ช่วง Preference เท่ากับ 0
- หลีกเลี่ยงการเรียนวิชาเดิมในวันติดกัน
- อนุญาตให้บางคาบยังไม่ถูกจัด เพื่อให้เห็นจุดติดขัด
- น้ำหนัก Preference ความพอดีของห้อง และโทษคาบเย็น

## การนำขึ้น Streamlit ภายหลัง

นำโฟลเดอร์นี้ขึ้น Git repository โดยเก็บ `app.py`, `scheduler/`,
`sample_data/`, `requirements.txt`, `runtime.txt` และ `.streamlit/config.toml`
จากนั้นกำหนดไฟล์เริ่มต้นเป็น `app.py` บนบริการโฮสต์ Streamlit ที่เลือก

แอปไม่มีระบบยืนยันตัวตนในตัว หากข้อมูลจริงเป็นข้อมูลส่วนบุคคล
ควรเลือกพื้นที่โฮสต์และสิทธิ์เข้าถึง repository ให้เหมาะกับนโยบายของหน่วยงาน
